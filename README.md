# Nytuo Apps

## How do I install these formulae?

`brew install nytuo/apps/<formula>`

Or `brew tap nytuo/apps` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nytuo/apps"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
